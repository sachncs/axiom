# Historical native matching Engine results

The separate native matching Engine was removed from the product on 2026-10-04.
These raw reports are retained unchanged for engineering history and provenance.
They do not describe or qualify the supported `basic` and `multilevel` paper
matching modes. `Packed` storage remains supported, but these measurements timed
the removed matching algorithm, not graph storage in isolation.

The result set includes short million-vertex throughput runs, sparse partner
index diagnostics, and derived graph-occupancy experiments. Do not combine these
rates or memory figures with current paper-mode results or use them as a current
production sizing claim.
