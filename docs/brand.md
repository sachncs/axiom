# Axiom brand assets

Updated 2026-10-03. The paired-rail mark replaces the generic letter-A tile and
the old thin triangle. Two facing rails frame two matching bars: a compact,
recognizable silhouette for graph matching and coherent state. This is a brand
symbol, not a rendering of an algorithm or a mathematical guarantee.

## Canonical geometry

`site/public/mark.svg` defines the two paths. `Brand.astro` imports this vector
directly for both header and footer. Inline marks use the theme's teal/rust
colors; standalone icons use an ivory background so they remain readable in
light and dark browser chrome. No webfont, animation or client script is needed.

The same paths appear in `favicon.svg`, the README's `logo.svg`, and `og.svg`.
The site checker rejects divergent geometry, missing header/footer marks and
missing current favicon/touch metadata on any published page.

## Palette and exports

- Ivory `#f4f3ed`, charcoal `#192b25`, teal `#20684f`, rust `#a9502d`.
- SVG favicon plus 16/32px PNG fallbacks; 180px Apple touch icon.
- 1200×630 social image, exported from `og.svg`; current cache version is explicit
  in page metadata. SVG sources remain editable and are the authority.

Raster assets are normal vector exports using the existing local Sharp runtime;
they are not separately hand-painted or generated by a second design system.
Keep square icon geometry centered and preserve the rails' negative space.
Use the mark with the lowercase `axiom` wordmark in navigation, not unrelated
letter tiles. Check the small exports at their actual size after any change.

The product page has no canvas simulation or scroll-reveal dependency. Its
eight-vertex trace is certified by executable installed-package examples,
including every edge/partner after reopen and an incompatible retry rejection.
