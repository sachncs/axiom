## Current interpretation

The implementation supports only Basic and Multilevel matching, with Basic the
default. Both modes use the durable `Durable`/`Service` path and implement
bounded atomic batches and version-coherent read snapshots. The removed native
matcher and checkpoint path are not supported. Implementation is not
qualification: paper performance, repeatability/skew, recovery-at-scale, and
deployment/resource gates remain open. Hardware power-loss qualification is
deferred; arbitrary IDs, dynamic vertices, and billion-node support are not
implemented or claimed. See [current measured status](status.md) for evidence
boundaries and explicitly historical native results.
